# Worker dispatch attention

An owner may explicitly configure a short-lived worker attention route for one project, role, installation, exact EHS session and current role generation. Routes are disabled until configured and are independent from the orchestrator route. Use the owner-only `GET` or `PUT /api/hub/v1/projects/{project}/worker-attention-routes/{role}` and `POST .../{role}/revoke` endpoints. Existing project, task-kind, role, session and grant checks remain in force; the route grants no additional capability.

A client holding that exact session can connect to the existing `/api/agent-sessions/v1/hub-attention-stream` with `project`, `generation`, and `role`. Content-free hints prompt an explicit `hub_worker_dispatch_pending` read; `hub_worker_dispatch_ack` records a separate receipt after the client accepts it. The dispatch is the durable record, so reconnect performs catch-up even when a hint was missed. Only open, currently dispatched items whose recorded target binding exactly matches the route are eligible. Legacy unbound or prior-session assignments remain discoverable through `hub_role_dispatch_inbox` but are not silently reassigned or notified to the new holder. Acknowledgments suppress repeat hints for the same dispatch and session; retry in the same still-authorized generation, including after route renewal, returns the same receipt. After task closure, dispatch change, revocation or role transfer, retry fails closed.

The route and hints do not launch a client or inject a turn. A receipt is a client assertion, not evidence of wake, execution, task completion or takeover. Existing owner grants, pause state, project activity and exact session/lease are revalidated. The stream is event-driven; it does not poll an AI inbox. Operators may explicitly run the foreground `engineering_hub.attention_client` with the exact `--role`; see `attention-client.md`. It is not an automatically started worker and does not inject an agent turn.

Owners can review receipts through `GET /api/hub/v1/projects/{project}/worker-attention-receipts/{role}`; this remains available for an archived project as historical evidence. Receipts are scoped to the named project and role and paginated in UUID order.
